# 哥德巴赫猜想：部分结果与可复现核验

## 1. 题目与记号

题目要求证明：任一大于 2 的偶数都可以写成两个素数之和。

设 `n` 为偶数且 `n > 2`。素数指大于 1 且只有 1 和自身两个正因子的整数，记素数集为 `P`。定义表示函数

    r(n) = #{(p, q) in P x P : p + q = n}.

题目等价于：对每个偶数 `n > 2`，都有 `r(n) >= 1`。

本提交**不声称**证明哥德巴赫猜想。下面给出已经完成的严格结论、有限范围内的可复现核验，以及明确未完成的部分。

## 2. 已完成的严格结论

### 2.1 引理 1（Euclid）

素数有无穷多个。

**证明.** 若素数只有有限个 `p1, ..., pk`，令 `N = p1 * ... * pk + 1`。`N` 的任一素因子都不在 `p1, ..., pk` 中，矛盾。故素数无穷多。□

### 2.2 引理 2（Bertrand）

对任意整数 `m > 1`，存在素数 `q` 满足 `m < q < 2m`。

**证明思路.** 考察二项式系数 `C(2m, m)`。若区间 `(m, 2m)` 内没有素数，则 `C(2m, m)` 的全部素因子都不超过 `m`，于是它不超过所有不超过 `m` 的素数的标准幂次上界；另一方面 `C(2m, m) >= 4^m / (2m + 1)`，且每个素因子 `p <= 2m` 在 `C(2m, m)` 中的指数不超过 `log_p(2m)`，把这两条估计合并会得到矛盾。故 `(m, 2m)` 内必有素数。□

### 2.3 有限核验

`build/main.py` 在 `[4, 200000]` 上逐项复核哥德巴赫分解：

1. 用 Eratosthenes 筛构造 `[2, LIMIT]` 的素性表；
2. 对每个偶数 `n` 寻找最小的素数 `p`，使 `n - p` 也是素数；
3. 复核 `p`、`q` 的素性、`p + q = n` 与顺序约束；
4. 把每个见证 `n = p + q` 写入 SHA-256 证书。

任一偶数找不到见证、或见证未通过复核，程序即以非零状态退出；全部通过时输出 `RESULT: PASS`、核验个数、最大素数和证书摘要。

## 4. 可复现性

在仓库根目录运行：

    python build/main.py

程序不依赖第三方库；每次运行都会重新计算素性表、逐项复核并重新生成 SHA-256 证书。输出中的核验个数、最大素数与证书摘要可用于比对。

## 5. 结论（部分）

本提交严格证明了素数无穷多与 Bertrand 引理，并在 `[4, 200000]` 上完成了可复现的哥德巴赫分解核验；一般情形的配对引理仍未解决。结论与代码行为一致：这是部分结果，不是完整证明。
